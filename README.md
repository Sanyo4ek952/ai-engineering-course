# AI Engineering Course — стартовый комплект (v0.1)

Это **каркас курса и двухнедельного пилота**, а не утверждённая полная учебная программа.

## Цель
Развивать компетенции frontend-инженера (React/TypeScript/архитектура), который понимает backend и уверенно использует AI-инструменты для разработки. Главный критерий — способность **объяснить и защитить** решение без AI.

## Где что делать

- **GitHub (private)**: основной источник истины о курсе, версия документов и доказательства выполнения.
- **ChatGPT Project**: объяснения, вопросы, диагностика, ревью. В настройках проекта использовать текст `CHATGPT_PROJECT_INSTRUCTIONS.md`.
- **Codex**: задачи в локальном клоне этого же репозитория. `AGENTS.md` задаёт ограничения и ссылки на документы.

**Важное ограничение:** ни ChatGPT Project, ни Codex автоматически не гарантируют синхронизацию. После занятия изменения `tracking/STATE.md` должны попасть в GitHub коммитом. Если наставник не имеет доступа на запись, он подготавливает патч/текст, а пользователь применяет его сам.

## Начало
1. Уточнить `COURSE.md` и утверждать программу только после диагностики.
2. Создать приватный GitHub-репозиторий `ai-engineering-course`.
3. Поместить туда содержимое этой папки.
4. Создать ChatGPT Project `AI Engineering — обучение`; вставить инструкции из `CHATGPT_PROJECT_INSTRUCTIONS.md`.
5. В первом чате проекта предоставить доступ к репозиторию или прикрепить `COURSE.md`, `SYLLABUS.md` и `tracking/STATE.md` и запустить модуль `modules/P0-diagnostic/LESSON.md`.
6. Открывать Codex **только для конкретного задания** из курса, а не просить его заново придумывать всю программу.

## Удобный запуск занятия
Попросить ChatGPT: «Проверь актуальные COURSE.md, SYLLABUS.md, RUBRIC.md и tracking/STATE.md. Если не имеешь доступа — скажи об этом. Продолжи текущий урок согласно STATE.md, сохрани незавершённые задачи и не меняй программу без согласования».

## Правило завершения
Не отмечать урок как выполненный без проверенного артефакта и объяснения решения. В конце фиксировать состояние. Хранить в репозитории только материалы обучения и обезличенные примеры, **никаких ключей API, персональных данных клиентов и конфиденциального кода реальных проектов**.
