# SYLLABUS.md — основная программа v1.0

**Утверждена студентом:** 2026-11-05. **Статус:** APPROVED.  
**Пилот P0:** досрочно завершён как проверка процесса (D-002), не как зачёт всех навыков.  
**Цель:** подготовка к оплачиваемой frontend-разработке с сильными React/TypeScript, backend-грамотностью и AI engineering; не обещание трудоустройства или звания Middle по календарю.

## Режим и темп
- **16 учебных недель**, ориентир **8–10 ч/нед**, суммарно **128–160 часов**; при 6 ч/нед — ориентировочно 21–27 недель на тот же объём. Неделя — единица планирования, не обязательная календарная дата.
- 2 занятия по ~4–5 часов в неделю: самостоятельная попытка → теория и разбор → практика → тестирование и review → самостоятельная защита.
- **Один продукт:** SupportDesk AI, CRM обработки обращений. Сначала mock API и frontend, затем реальный API/DB/auth, потом AI, надёжность и автоматизация.
- На всех этапах использовать Codex после собственной постановки требований; модуль M5 посвящён более глубоким агентным процессам. Без слепой генерации.
- Программный стек детализируется через ADR в уроке, не фиксируем преждевременно версии/провайдеров. Ориентир React + TypeScript, RTK Query, Node.js/Fastify, PostgreSQL, Vitest, Playwright; RAG и MCP только для конкретных сценариев.
- **Зачёт по RUBRIC.md:** применимые критерии/веса до начала урока, обычно 40/30/20/10, ориентир ≥80/100 и отсутствие критической ошибки безопасности; evidence обязателен. Если самостоятельный ответ слаб — `needs-evidence`, не фальшивый `completed`.

- Гейты M1 → M2 → M3 → M4 → M5 → M6: каждый модуль требует воспроизводимых доказательств; не закрывать модуль по наличию AI-кода.

- Через 1–3 следующих занятия повторно проверять освоенное; отмечать отдельно первичную и повторную сдачу.
- Между модулями сверять актуальные официальные API/инструменты и выборочные требования российских frontend-вакансий; в `tracking/DECISIONS.md` записывать существенные изменения с источником и причиной. Следовать целям, а не хайпу.
- Утверждение маршрута не означает, что подготовлены полные тексты всех 32 уроков. Их подробности пишутся **последовательно**, без изменений обязательных результатов без согласия.
