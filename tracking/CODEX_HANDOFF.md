# CODEX_HANDOFF — передача утверждённой программы в Codex

**Дата:** 2026-11-05. Спецификация основного учебного маршрута утверждена студентом; GitHub — источник истины.

## Ответственность
ChatGPT — наставник, техническая и методическая проверка; студент — самостоятельное решение и утверждение; Codex — инженерная помощь при реализации конкретного урока, работа с кодом и файлами по разрешённому scope. Codex не оценивает собственный результат как зачтённый без независимой проверки.

## Порядок передачи задачи в Codex
1. Прочитать `tracking/STATE.md`, `COURSE.md`, `SYLLABUS.md`, `RUBRIC.md`, файл активного урока и релевантные `AGENTS.md`.
2. Назвать активный урок, ожидаемый артефакт, критерии и допустимые файлы.
3. Сначала предложить короткий план, не создавать лишнюю инфраструктуру.
4. Выполнять только согласованную инженерную часть, сохранять исходную попытку студента; не писать за него самостоятельную защиту.
5. Передать diff, команды проверок, результаты и риски. Никаких секретов, клиентских данных и кода реальной работы.
6. Обновлять `tracking/STATE.md` только по явной просьбе студента и после подтверждённого результата; коммит/проверка GitHub обязательны.
