# Codex: repository instructions

This repository is an **education system first**, an application second.

- Do not invent curriculum goals or mark progress complete.
- For course-related implementation work, use the explicitly specified assignment, `COURSE.md`, and relevant sections of `SYLLABUS.md`/`RUBRIC.md`.
- Do not modify curriculum or `tracking/STATE.md` unless the user explicitly requests it.
- Before coding, summarize the requested scope, acceptance criteria and risks.
- Prefer minimal, reviewable diffs; run relevant tests if available; report commands and outcomes truthfully.
- Do not generate full solutions to independent/no-AI assessment exercises unless explicitly authorized by the student after the assessment.
- Never commit credentials, customer data, or confidential real-project source code.
- When encountering an adjacent topic, mention it briefly rather than changing the assignment scope.
- These instructions are for Codex; ChatGPT Project instructions are in `CHATGPT_PROJECT_INSTRUCTIONS.md`.
